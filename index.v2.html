ARCHITECTURAL DOSSIER // TATHYA (तथ्य) RESEARCH PHASE

01 Research Hypothesis & Failure Modes

State-of-the-art LLMs trained on standard web Hindi (Manak Hindi) experience catastrophic token fragmentation when parsing dialectal inputs from Haryana, Punjab, and Bihar. A 6-token colloquial query often blows up into 34+ byte fragments, degrading attention weights and yielding hallucinations on critical civic information.

02 Verification Layer Architecture

Tathya implements a dual-pass evaluation pipeline: an acoustic/orthographic normalizer paired with an assertion boundary checker. Civic and health queries are grounded against audited municipal tables before generating user responses.

03 Architectural Retrospective & Failure Analysis

What Broke: Relying purely on synthetically generated dialect evaluations produced synthetic hallucinations. Correction: Transitioned to collecting authentic local voice notes and community radio transcripts to construct an uncorrupted benchmark dataset.

ARCHITECTURAL DOSSIER // STRATUM CONCEPT STAGE

01 Simulation Engine Model

Stratum models marketing and venture aptitude by discarding static case interviews in favor of a live deterministic finite-state machine. Candidates allocate capital across volatile simulated bidding channels (simulated Meta/Google ad auctions) subject to exogenous algorithmic shocks.

02 Latency & Capital Efficiency Audits

Every keystroke, budget allocation, and pivot timestamp is logged into an immutable session ledger. Candidates are evaluated on mathematical resilience, capital drawdowns, and recovery calculus rather than articulate retrospective rationalizations.

03 Retrospective: Headless vs Full UI

Initial Pitfall: Attempted to build high-polish canvas dashboards prematurely. Pivot: Stripped the UI to engineer a headless, deterministic state machine with verifiable seeds first, ensuring identical scenario playback across interview cohorts.

ARCHITECTURAL DOSSIER // FLOW STATE LOCAL BUILD

01 Local-First Philosophy & Zero-OAuth Sync

Modern developer productivity tools are saturated with telemetry beacons, remote websocket heartbeats, and invasive analytics. Flow State enforces total air-gap capability: calendar events synchronize via direct RFC 5545 .ics parsing with zero external network handshakes.

02 16-Bit Procedural Sound Engine

Replaced bloated streaming audio players and compressed MP3 loops with a native 44.1kHz Web Audio procedural sine synthesizer. Generates custom brown and pink noise with mathematical purity at microscopic CPU usage (<0.5%).

03 Retrospective: Discarding Electron

Critical Lesson: Bundling Chromium for a productivity tool consumed 450MB of RAM—the antithesis of lightweight flow. Rebuilt the desktop shell around native OS webviews to maintain sub-40MB memory footprints.

ARCHITECTURAL DOSSIER // KRAMA (क्रम) STUDENT UTILITY

01 The 75% Cutoff Recovery Calculus

Indian undergraduate regulations mandate strict 75% attendance for examination eligibility. Krama eliminates intuitive guesswork by modeling class attendance as a calculus curve, calculating the minimum mandatory presence required to recover from unexpected illness or collegiate competition travel.

02 Offline Timetable Optimization

Operates 100% on-device using local indexed storage. Accommodates shifting lab slots, campus holiday calendars, and substitute sessions without requiring administrative portal credentials.

03 Retrospective: Handling Edge Schedules

Edge Case Failure: Irregular university schedules with rotational odd/even week cycles broke simple modulo parsers. Fix: Implemented day-by-day deterministic state transitions keyed to official university academic calendars.

⚡ Token Fragmentation & Failure Mechanism

Tokenizer Breakdown: Standard Indic LLM tokenizers trained on formal web Hindi (Manak Hindi) lack vocabulary IDs for regional colloquial markers (म्हारी, सैं). Words are shattered into byte-level subword fragments, inflating token length.

Downstream Failure Mode: Attention weights dilute across inflated byte sequences, causing critical entity degradation over state welfare policy (लाडो योजना) and resulting in civic query hallucinations.

Tathya Verification Layer: Normalizes colloquial orthography and assertion boundaries against audited municipal scheme records before response generation.
