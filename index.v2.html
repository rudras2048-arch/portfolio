01 Research Hypothesis & Failure Modes

LLMs trained on standard web Hindi (Manak Hindi) suffer subword token fragmentation on dialectal inputs from Haryana, Punjab, and Bihar. Colloquial words split into multiple byte fragments, inflating sequence length and diluting attention over civic entities.

02 Verification Layer Architecture

Tathya pairs orthographic normalization with deterministic assertion boundary checks, grounding civic and public-health queries against audited municipal records prior to output generation.

✦ Retrospective: Grounding in Authentic Speech
“Synthetically generated dialect prompts introduced artificial phrasing. Shifting to native voice notes and community radio transcripts grounded the evaluation set in real spoken syntax.”

Marker UTF-8 Bytes (म्हारी): E0 A4 AE E0 A5 8D E0 A4 B9 E0 A4 BE … (18 UTF-8 bytes)
STANDARD HINDI TOKENS 10 whole tokens · 108 UTF-8 bytes
[हमारी][सरकार][की][लाडो][योजना][के][क्या][लाभ][हैं][?]

Colloquial markers "म्हारी" and "सैं" lack whole-word Manak Hindi entries and fracture across conjunct and matra boundaries.

⚡ Token Fragmentation & Failure Mechanism

Tokenizer Breakdown: Standard Indic LLM tokenizers trained on formal web Hindi (Manak Hindi) lack vocabulary IDs for regional colloquial markers (म्हारी, सैं). Words are shattered into byte-level subword fragments, inflating token length.

Downstream Failure Mode: Attention weights dilute across inflated byte sequences, causing critical entity degradation over state welfare policy (लाडो योजना) and resulting in civic query hallucinations.

Tathya Verification Layer: Normalizes colloquial orthography and assertion boundaries against audited municipal scheme records before response generation.
